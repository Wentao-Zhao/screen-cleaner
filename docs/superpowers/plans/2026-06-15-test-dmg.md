# 屏幕清洁测试版 DMG 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 为屏幕清洁生成包含应用、Applications 快捷方式和首次打开说明的测试版 DMG。

**架构：** 新增独立 Shell 脚本，先复用现有 App 打包脚本，再创建临时 DMG 根目录并调用系统 `hdiutil` 生成压缩镜像。README 记录生成和分发限制。

**技术栈：** zsh、hdiutil、codesign、plutil
